01 / Positioning

cc is an IDE where your coding agents run side by side, and the one that needs you comes to you.

Who it is for:

  • Developers on Windows 10 or 11 who run more than one CLI coding agent at once, such as Claude Code and Codex, and lose track of which one is waiting.
  • People who want agent sessions to keep running when the window closes or crashes.
  • People who want agents to use a browser or Windows apps, with risky actions stopping for their approval.
  • People who want local-only tools: no account and no telemetry.

Two other ways to say it

LineTrade-off
A workspace for many CLI agents that shows you which one is waiting.Clear on the wall. Hides the editor and source control.
A Windows IDE where agents can drive a browser and your apps, and anything risky stops for you.Most distinctive feature. Leads with the part people worry about most (see FAQ 1).

Recommendation: use the main line. It matches the README's own first line ("an IDE built around your coding agents"). Claude Code is Anthropic's and Codex is OpenAI's; cc is not affiliated with either, or with Google.

Working: stars

Source 3 tracked 138 AI-tool repos after HN exposure. They averaged 121 stars at 24 h and 289 at one week. Those repos all got HN attention, and an average is pulled up by a few big hits. So the plan takes 10% of each. The 10% is a planning assumption, not a measured number.

  • Day 1: 121 × 0.10 = 12.1, so 12.
  • Day 7: 289 × 0.10 = 28.9, rounded down to 25.
  • Day 28: 25 + 15 = 40. Source 2 found 92% of star gains are over by 48 h, so the extra 15 needs a second push, such as a newsletter mention. Treat it as a stretch.

Why so low: source 1 found only 2.9% of Show HN posts reach 50 points, and source 2 found the median post scores 2. A post that does not catch on will land below these numbers.

Working: traffic

Vue's first day (source 8) brought 1,880 unique GitHub visitors. The plan uses about 5% of that: 100 ÷ 1,880 = 5.3%, so 100 day-1 visitors. Views are set at 1.5 × visitors: 100 × 1.5 = 150. The 1.5 ratio is an assumption.

GitHub reports unique visitors per day. Adding daily uniques double-counts returning people, so there is no 28-day unique target.

Working: clones and issues

No source gives clone or issue rates for a launch. Clones assume 13% of views: 150 × 0.13 = 19.5, so 20 on day 1. Issues are a capacity target for one maintainer, not a forecast. Confidence is low on both.

How to measure

  • Stars and issues: the repo page and the issues list, filtered by creation date after 3 December.
  • Views, visitors, clones: Insights → Traffic. GitHub keeps only the last 14 days (GitHub Docs). Save it daily:
    gh api repos/Wasif-ZA/metatrooper/traffic/views > views-YYYY-MM-DD.json
    gh api repos/Wasif-ZA/metatrooper/traffic/clones > clones-YYYY-MM-DD.json
    Keep the files outside the repo.
  • Where visitors came from: gh api repos/Wasif-ZA/metatrooper/traffic/popular/referrers. Use it to check the channel ranking against real results.

05 / Objections FAQ

Answers drawn only from the README.

Is it safe to let agents drive my browser and Windows apps?

Risky actions stop for you first. In a browser pane, typing into a password field, typing text that looks like a credential, and clicking buttons named like Send, Submit, Pay, Delete or Publish all wait for your approval. The first input on a new site also asks first. On the desktop, an agent acts only on windows you give it. Admin windows and the cc window can never be given. Ctrl+Alt+Q pauses all agent input at once. A watcher pauses agents if input comes from another program, or the desktop changes while you are away. The honest limit: there is no sandbox for agents' code yet, so agents and their commands run with your permissions.

Why AGPL? What does it mean for me?

The licence is split by folder. core/, workbench/, sandbox/ and anything without its own licence file are AGPL-3.0-only. sdk/, plugins/*/, skills/, engines/ and router/ are MIT. The public formats listed in contracts/LICENSE-MIT are MIT too. If you plan to change cc and share or host it, read the licence text first. This page is not legal advice.

Windows only?

Yes, for now. The README lists Windows 10 or 11 as a requirement, and its steps were tested on Windows 11. Computer use is built on UI Automation, which ships with Windows. Secrets are encrypted with your Windows login (DPAPI). No other system is listed.

No installer?

Not yet. You clone the repo and run it from source. You need Node 24.16 or newer and at least one agent CLI installed and signed in: claude, codex, gemini or agy. Setup is two npm ci runs, node core/cli.ts start, then npm run dev. An installer is the top item on the checklist below. cc is not affiliated with Anthropic, OpenAI or Google.

Why not just tmux, or VS Code with terminals?

Those show terminals. They do not tell you which agent is waiting. In cc, a tile that asks a question turns orange and moves to the big slot, and Alt+J jumps to the session that has waited longest. A background service owns the terminals, so agents keep working if the window closes, and sessions come back after a restart. The editor marks files an agent changed, and a comment on a diff line goes to that agent as your next message. cc also has an "Open in VS Code" action, so you can keep using both.

06 / Risks

Two must be dealt with before launch day.

Risk 1: the name "cc" clashes twice fix before launch

What
cc is the standard C compiler command on Unix-like systems. "CC" is also a common nickname for Claude Code, which cc runs. cc is not affiliated with Anthropic, OpenAI or Google.
Why it hurts
Search: a search for "cc" returns compilers, Creative Commons and much else, so people cannot find the project without the exact link. Confusion: people may think cc is an Anthropic product, or Anthropic may object to the similarity.
How likely
Search problem: certain. Confusion: likely, because Claude Code is the first engine the README names.
Do before launch
Check trademark registers and Anthropic's published brand rules for third-party tools. Use a longer search name in every title, such as "cc, an IDE for coding agents". Put the not-affiliated line in every post. Do not ship a command called cc; it would shadow the compiler. If the checks look bad, rename now, while the public name is new. Rename later costs more.

Risk 2: Ouros and MetaTrooper leftovers fix before launch

What
On 2026-11-18, tracked files mentioned "MetaTrooper" 1,274 times across 349 files, and "Ouros" 783 times across 187 files. The README already says the repo, the troop command, ~/.metatrooper/ and package names still use MetaTrooper.
Why it hurts
A visitor from a "cc" post sees OUROS in the screenshots and the window, and MetaTrooper in the URL. It looks like a half-finished rename.
How likely
Certain. The repo URL is github.com/Wasif-ZA/metatrooper.
Visible leftovers found
  • All 6 screenshots in assets/ouros/ show the OUROS wordmark and branch names like ouros/rate-limit.
  • UI text: workbench/src/demo.ts ('Ouros (demo)'), workbench/src/main.ts (error box titled Ouros), workbench/renderer/app.js ("Ouros never commits…"), workbench/ui/src/settings.jsx ("Keep runs going when Ouros closes" and others), workbench/ui/src/addons.jsx, workbench/src/browser/panes.ts ("Ouros blocked this page"), workbench/src/report-issue.ts (issue titles start "Ouros:").
  • Names users will type or see: packages metatrooper, @metatrooper/core, @metatrooper/workbench, @metatrooper/sdk; the troop command; ~/.metatrooper/; the pipe \\.\pipe\metatrooper; the MCP servers metatrooper-browser and metatrooper-desktop.
Do before launch
Change every on-screen "Ouros" to "cc". Retake every screenshot from the running window. Leave package, folder and pipe names for a later release, and keep the README line that explains them. Decide whether to rename the GitHub repo; GitHub redirects old repo links after a rename, but check this before relying on it.

Risk 3: screenshots may not show the product that runs today

What
wall.png shows chat-style tiles, while the README describes each tile as a live terminal. today.png shows a "Today" screen and rewind.png a rewind screen; neither is in the README's list of screens. jobs.png shows non-coding tasks (a spreadsheet, a sales pipeline, a poster). In wall.png, a tile has its Claude tab selected while its footer says Gemini needs you.
Why it hurts
HN readers who install it and see something different will say so in the thread.
Do before launch
Use only captures of the running window. Keep design mockups out of the README and the posts.

Risk 4: timing and a single maintainer

What
The post goes up at 04:00 Sydney. The follow-up weeks run into Christmas. One person answers everything.
Do
Sleep early on 3 December. Have the first comment and FAQ answers ready to paste. Post the holiday reply schedule on the repo.
