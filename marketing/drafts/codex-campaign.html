01 / Positioning

One window for coding agents that need your attention.

cc is a Windows-first IDE that puts CLI coding agents in live terminals and shows which one is waiting for you.

For: developers who run several coding agents while they inspect and edit code. cc runs from source today.

Claude Code, Codex and Gemini are names of supported external CLIs. cc is not affiliated with Anthropic, OpenAI or Google.
