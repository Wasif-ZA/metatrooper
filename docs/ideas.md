## Framing worth keeping

**Idea 12 reframes the project.** CallRouter learns the CLAUDE.md nobody wrote. A
hand-written rule like "get the time with `now-iso.sh`, never `date`" is exactly a
template, except extracted from what actually ran rather than typed out by hand, and
scoped per project.

**Idea 16 has an unusually good fit.** Jev returns typed probabilistic decisions rather
than text, priced at $0.042 per million input tokens, which is cheap enough to run
before every tool call. Released in limited early access 2026-09-15. Tool selection is
exactly the shape it was built for: unstructured state in, typed decision out.

**Idea 29 is the competitive answer.** Without a shipped catalog the leaderboard starts
empty, so on a fresh install CallRouter knows nothing and helps nobody. It would be
useful to exactly one person, the one whose transcripts trained it.

**Idea 17 inverted the architecture.** All three target hosts expose MCP
(`codex mcp`, `agy mcp`, and Claude Code's config), but only Claude Code has hooks. So
MCP is the portable spine and hooks are an accelerator on one host. Building on hooks as
the foundation would have stranded two thirds of the target surface.

## Where the ideas stand against the evidence

`measurement.md` scored the main ones by ceiling, meaning the saving if the feature
worked perfectly:

| Idea group | Ceiling | Hours | Tokens per hour |
|------------|--------:|------:|----------------:|
| 5, 6, 25 capping and rewriting | 666,041 (34.7%) | 10 | 66,600 |
| 12 to 14 templates | 114,709 (6.0%) | 24 | 4,800 |
| 20 to 23 failure intelligence | 89,478 (4.7%) | 22 | 4,100 |
| 9 to 11 cache | 2,353 (0.12%) | 14 | 170 |

The cache ceiling is the one to remember: 33 exact repeat commands out of 2,886. Headroom's
independent audit found the same thing from the other direction, reporting zero identical
repeats, zero subset containment and zero write-readback across all recorded Read calls.
Two tools, two methods, same verdict.

## What was considered and rejected

Full list with reasons in `decisions.md`. The short version: 23 things cut, of which five
because Headroom or Claude Code already ships them, four because the measurement does not
support them, nine on architecture, two on safety and five on naming. Every cut is tagged
`revisit: v2-jev`, because several were made only because a rule-based engine cannot judge
safely enough, and a typed probabilistic decider changes that calculation.
