# reference-first-design

Invented looks get rejected; polish without a reference reads as "no change". Every design
decision traces to a real product the user can see.

If the user already gave an exact design, or says to skip references, build that and stop here.

## 1. Ask before building

If the user is about to leave the agent alone with design work, ask first, one question at a
time: which product and screen each part copies, which regions and details it must carry,
what to keep from the current design, and what is out. Write the answers into the plan.

## 2. Collect references

- Real in-product screenshots or recordings, not marketing crops or mock-ups. No real shot of
  an option means drop the option.
- For motion, look at the reference's code or a screen recording, not a description.
- Put them on a contact sheet (`references.html`), rate each strong, medium or weak with the
  reason, and drop the weak ones.
- Check the project's existing assets and earlier research first (`reuse-first`).

## 3. Variants that differ on one layer

Build 3 to 5 throwaway variants that change exactly one layer: structure, then material
(colour, type, texture), then motion. Each names the reference it borrows from. Build them
outside the project tree. Use the component library the project already has, not hand-built
copies of it.

## 4. Judge against the reference

Show each variant beside its reference on one board. Score how close it gets to what the
reference does well, not how good it looks in isolation. A variant further from its reference
than the last round went the wrong way.

## 5. Apply

Port only the picked variant into the project, inside the existing layout. A pick means keep
refining, not final. Never commit; when the user calls it final, give them the commit command.
Show before and after side by side; if the difference is not visible at a glance, it is not done.

## Rules

- No glows, gradient washes or glass panels standing in for a real image.
- Copy layout and interaction ideas, not another product's name, logo or artwork.
- After a rejected round, research again before generating again.
