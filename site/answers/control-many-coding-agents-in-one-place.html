How do I control many coding agents from one place?

Put everything an agent needs from you in one window: its terminal, its changes, its questions and the browser it uses. cc does that. It is a carbon copy of the apps you already code in, an editor, a terminal wall, an inbox and a browser, rebuilt as one Windows app with your agents built in.

What you juggle without it

  • An editor to read what each agent changed.
  • One terminal per agent, and no sign of which one is waiting.
  • A browser to check what an agent built, and screenshots pasted back to it.
  • Notes on which agent is doing what.

The same apps, one window

ScreenLooks likeWhat the agents do there
HomeA chat app with a task listStart a task from a chat box. Each task shows its agents, subagents and steps.
IDEA VS Code style editorFiles an agent changed are marked. A comment on a diff line goes to that agent as your next message.
WallA grid of terminalsEvery agent is a live tile. The one waiting for you moves to the big slot. Its diff, git and browser open beside it.
Needs youAn inbox laid out like an issue trackerEvery question and approval waiting on you, with filters and labels. You answer from here.

What is built in around them

  • A background service owns every terminal, so closing the window does not stop the agents. After a restart, live sessions resume, at most 3 at a time.
  • Agents can drive browser panes in the app. Password fields, new sites and Send or Delete buttons stop for your approval, and only the window can approve.
  • Ctrl+K searches sessions, commands and the text in every live terminal.
  • It runs 7 CLI agents, including Claude Code, Codex and Gemini CLI. You install and sign in to each yourself; cc never reads their login tokens.

cc is free, open source (AGPL-3.0 core) and pre-release. It is Windows first, installs from source and needs Node 24.16 or newer. No account, no telemetry. Steps: Quickstart.
