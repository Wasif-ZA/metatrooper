How do I run several Claude Code sessions at once?

Give each session its own git worktree. Then no two sessions edit the same files. Run each session in its own terminal, and merge its branch when the task is done.

Why a worktree per session

Two sessions in one folder write over each other's files and fight over one git index. A worktree is a second checkout of the same repo on its own branch, sharing one .git. Each session gets a folder to itself.

The plain way, with git and terminals

git worktree add ../myapp-login -b login
git worktree add ../myapp-search -b search
cd ../myapp-login  && claude   # terminal 1
cd ../myapp-search && claude   # terminal 2

When a task is done, review its diff, merge the branch, then run git worktree remove ../myapp-login.

What gets hard past two or three sessions:

  • You cannot see which session is waiting for an answer or a permission without checking each terminal.
  • Closing a terminal ends its session.
  • If two tasks change the same file, you get a merge conflict when you combine the branches.

Each worktree needs its own install of dependencies, such as node_modules. Budget the disk space and install time per worktree.

The same thing in cc

cc is a free, open-source Windows app that runs coding agents side by side. A background service owns each agent's terminal, so closing the window does not stop them.

troop launch claude --worktree login --prompt "Add the login form"
troop launch claude --worktree search --prompt "Add search to the header"
troop launch --jobs jobs.json   # several at once from one file
troop owners                    # which session changed which file

From a source install, troop means node core/cli.ts.

  • Every session is a tile on one wall. A session that asks a question turns orange and moves to the big slot.
  • Alt+J jumps to the session that has waited longest.
  • After a restart, cc resumes the sessions that were live, at most 3 at a time.
  • It runs Claude Code, Codex, Gemini CLI and other agent CLIs in the same way, 7 in all.

cc is pre-release. It is Windows first, installs from source and needs Node 24.16 or newer. Steps: Quickstart.
