Should I use cc or just run my agents in terminals?

For one or two agents, plain terminals are enough. Use cc when you run three or more agents and want them, your editor, your inbox of questions and a browser in one window instead of many. It also fits when you want agents to use a browser or Windows apps with approvals.

When to stay with terminals

  • You run one or two agents and can see both terminals.
  • You work on macOS or Linux and want a supported install today.
  • You want nothing added to ~/.claude/settings.json. cc installs hooks there; one command removes them.
  • You already use tmux or zellij and are happy checking panes yourself. Those keep sessions alive. They do not tell you which agent is waiting unless you set up bells or hooks yourself.

What cc does not do

  • It is not a sandbox. Agents and their commands run with your permissions.
  • Approvals do not stop a hostile program already running as you.
  • It does not sign in for you or read the CLIs' login tokens. You install and sign in to each CLI yourself.
