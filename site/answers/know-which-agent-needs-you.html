How do I know which coding agent is waiting for me?

Have each agent name itself when it stops. Claude Code runs a command through a hook when it needs you. Codex runs one through its notify setting. Make that command show a notification with the project folder in it, so you know which terminal to open.

The plain way

  • Claude Code: add a Notification hook in ~/.claude/settings.json that runs a command when Claude needs your permission or has been idle.
  • Codex: set notify in its config to a program that receives a JSON event when a turn finishes.
  • Other CLIs: check each one's docs for a notify or hook setting. Without one, you watch the terminal.

A notification names the folder. With four terminals open, you still switch to the right one by hand.

The same thing in cc

cc is a free, open-source Windows app that rebuilds an editor, a terminal wall, an inbox and a browser as one window, with your agents built in. Its inbox, Needs you, lists every question and approval waiting on you, and you answer from there. It installs the Claude Code hooks when it first launches Claude Code. troop hooks install --codex adds the Codex one. troop hooks uninstall --codex takes both out again, leaving the rest of each settings file as it was. From a source install, troop means node core/cli.ts.

  • Each tile says working, waiting for you, done or exited.
  • The tile that is waiting turns orange and moves to the big slot. If you were typing in the big slot, it waits 3 seconds first, so it never takes your keys.
  • Alt+J jumps to the session that has waited longest. Finished sessions fold to one-line bars.
  • No toast for the tile you are looking at. A toast names the task, not only the agent. Notifications can also go to ntfy, Slack, Discord, Teams, a webhook or a command.
  • Engines without hooks get a simpler status read from their process.

cc is pre-release, Windows first, and installs from source. Steps: Quickstart.
