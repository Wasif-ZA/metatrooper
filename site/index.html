What it does

MetaTrooper is a desktop workbench for the coding agents you already use. It runs them in the same window, lets two of them review the same change, and only calls a fix done when the fix carries proof: a test that fails without it and passes with it.

You stay in charge. A run stops at a gate whenever it needs your call, and nothing leaves your machine until you approve it.

How it is built

Your engines, your logins

Works with the official command line tools you install and sign in to yourself: Claude Code, Codex, Antigravity CLI. MetaTrooper never reads or stores your login.

Everything stays local

Runs, reviews and history live in one folder on your machine. No server, no account, nothing sent home.

Sandbox Coming later

Agents keep running on your machine as normal. The builds, tests and dev servers they start will run in one Docker container per project, with an Open sandbox button for a terminal into it and its files.
