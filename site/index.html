Four parts

Free and open source. It runs the official CLIs you install and sign in to yourself, and never reads their logins.

1

The wall

Every agent is a live terminal tile. The one waiting for you comes to the big slot.

2

Browser use

Agents drive browser panes in the app. New sites, passwords and send buttons wait for you.

3

Computer use

On Windows, agents act on the app windows you give them. One key takes over.

4

Core services

A background service owns the terminals. Sessions come back after a restart.

Needs you

The one that needs you comes to you.

  • True status. Working, waiting for you, done or exited, read from each agent's own hooks. A waiting tile says why.
  • No stolen keys. A waiting tile holds back for 3 s while you type in the big one.
  • Alt keys. Alt+J jumps to the longest wait. Your terminal keeps every Ctrl key.
  • Ctrl+K. One search over sessions, commands and the text in every terminal.
  • Per tile. Cost, context fill, changed files, and a preview chip for its dev server.

A browser your agents drive, with you in charge.

  • Approvals. Password fields, credential-like text and Send, Pay or Delete buttons stop at a card. Approve once, for the session, or reject.
  • Origins. The first input on a new site asks first. List trusted sites in the project config.
  • Secrets. An agent types {{secret:NAME}} into a password field on the saved site. It never sees the value.
  • Handoff. An agent can hand you the pane to sign in, then you give it back.
  • Its own cursor. Each agent's cursor glides to what it clicks, in its tile's colour. Your pointer never moves.

Your Windows apps, only the ones you give.

  • Grants. Pick Give window on a tile. The agent acts on that window and its own dialogs, nothing else.
  • Built in. It uses Windows UI Automation. Nothing extra is installed.
  • Take-over. Ctrl+Alt+Q pauses every agent's input, desktop and browser.
  • Watcher. Input from another program, or a change while you are away, pauses the agents and tells you.
  • Refused. The MetaTrooper window, admin windows and the secure desktop can never be given.

Core services

The parts you notice only when they are missing.

  • Terminals that surviveClose or crash the window and every agent keeps working.
  • Sessions come backAfter a restart, live sessions resume in the same layout, at most 3 at a time.
  • Ports and previewsA dev server an agent starts gets an Open preview chip. Agent panes reach only their own ports.
  • Quiet notificationsNo toast for the tile you are looking at. Optional ntfy, Slack, Discord, Teams or webhook.
  • Limits that carry onA Claude session that hit its limit continues when the limit resets.
  • Public APIA named pipe with JSON-RPC and stable, versioned methods. No TCP port.

Get started

There is no installer yet. You run it from a clone. You need Node 24.16 or newer and at least one agent CLI signed in.

git clone https://github.com/Wasif-ZA/metatrooper
cd metatrooper/core && npm ci
cd ../workbench && npm ci
npm run dev

The window starts the core service for you. Linux steps and every command are in the README.

Limits, stated plainly

  • Windows first. Linux is a beta from source, without computer use. macOS is not supported.
  • No installer or auto-update yet. You update with git pull.
  • Not a guard against hostile programs. Grants and approvals cover MetaTrooper's own tools. A program running as you can already drive your apps; the watcher tells you when it sees one.
  • Take-over is close to instant. A key already posted to an app may land just after the pause.
  • No sandbox for agents' code yet. Agents use your machine with your permissions.

Questions

What leaves my machine?

The core and the window make no network connection of their own. Your agents talk to their own vendors, as they do outside MetaTrooper. Pages you open in a browser pane load as in any browser.

Do I need an account or API keys?

No. Install and sign in to the official CLIs yourself. MetaTrooper runs them and never reads their login tokens.

What does it change on my machine?

State lives in ~/.metatrooper/. Launching Claude Code installs hooks in its settings file, and one command takes them out again, leaving the rest byte for byte.

Can an agent approve its own actions?

No. Only the window can approve, through a key agents are not given.

What is the licence?

The core and window are AGPL-3.0. The SDK, plugins, skills, engine files and public formats are MIT.
