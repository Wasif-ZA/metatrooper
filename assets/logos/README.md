# cc logo

Idea: every agent gets a tile; the one that needs you comes forward. The orange is the wall's
"waiting for you" colour.

| File | Use |
|---|---|
| `cc-icon.svg` | App icon and social avatar: a stack of agent cards, the front one orange and carrying cc_. 32 px and up. |
| `cc-mark.svg` | cc_ on the ink tile. Favicon, tab icon, anything 24 px and below. |
| `favicon.svg` | Same as `cc-mark.svg`. |
| `cc-glyph-ink.svg` | cc_ with no tile, for light backgrounds. Headers and wordmark use. |
| `cc-glyph-paper.svg` | cc_ with no tile, for dark backgrounds. |

Colours: ink `#151516`, paper `#f1f1ef`, wait orange `#ff7a1a` (dark) / `#c45200` (light). Only these three.
Clear space: one c-stroke width on every side. Never recolour the orange.

Picked 2026-11-18 from `marketing/logo-explore/board.html` (round 2 option 5 plus round 1 Claude 2).
The rejected nested-c mark is in `assets/archive/logos-nested-c/`.
